# Tool Use Benchmark

A practical benchmark for evaluating whether AI agents select and use tools correctly.

The initial benchmark will target approximately 100 tasks covering:

- Single-tool tasks
- Multi-tool tasks
- No-tool tasks
- Wrong-tool temptations
- Ambiguous requests
- Tool argument errors
- Tool failures
- Tool dependency
- Sequential tool use
- Parallel tool use
- Failure recovery

This is a placeholder. The benchmark itself is the major technical project for Weeks 2–4 — see [`ROADMAP.md`](../../ROADMAP.md).

In the meantime, [`notebooks/tools/tool_eval_v2.ipynb`](../../notebooks/tools/tool_eval_v2.ipynb) covers tool selection precision/recall, success rate, and cost-per-task on a smaller, ad-hoc set of scenarios.
